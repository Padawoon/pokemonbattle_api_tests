## Pokemonbattle API tests
#### API тесты для эндпоинтов /pokemons и /trainers

###  tests
* smoke - базовые проверки: получение тренера/ов по айди/городу, патч имени покемона, получение покемона по айди
* regress - к смоук-сьюту добавляена проверка получения тренеров по городу с сортировкой по уровню тренера

###  fixtures
* api_fixtures - вынесена фикстура с сессией и хедером для авторизации
* cleanup_and_create - вынесены фикстуры нокаута покемонов для очистки и создание нового покемона для теста

### data
* api_endpoints - вынесены эндпоинты, чтобы не торчали в файле с тестами
  * Можно было бы вынести в конфиг, но захотелось сделать вот так

### config
* api_config - базовый урл покебатла

### .env
* Пока содержит в себе только тренерский токен пользователя для авторизации

### conftest
* Содержит в себе линки на фикстуры проекта для pytest
